## 4. 三分支判定（§3 假设表口径）与升级条款

**前提审计**：§3 三分支设计于"R2F 载体修复验证轮"预期。实际：FM-③ 已撤出 t2_min_disparity（死亡袋原理性错轴+U3PO 袋有害+回放域不可判三重收杀），U3pp gates 臂=纯 cost 门——**无任何载体修复臂** ⟹ 分支 1/2（"计数降否"）形式上不可判，如实记 **premise-inapplicable**。

**可判的实质对照**（同流 odom×同阈 0.5m×同窗全轮）：
- route 域：U3′ 199/50 → U3pp 573/0 = **不降反增**（急冻族在线第 3 例加权重现；A1 odom=0 是因为旧 Bas 门在 odometry 放毒前拦停+毒面转移到传播流——是拦截时序运气，不是域好转）
- hover 域：0/0 → 0/1（唯一 1=reboot 工件）= 基本持平（当晚 A3/A4 各有门拦/干净）
- ground 域：0 → 0 持平
- **两型（急冻/急性腐化）均不降 ⟹ §3 分支 3"回 T2 重定因"成立**——且 T2 已由 R3 线承接重定因（在线 IMU/状态域事件、route 场景条件性 4/4 爆），A.4 与其**独立收敛**而非重复开案。

**D1 平滑可救性终判**：U3pp 残余全体=急性族（H-S1×1+第四形态×1）+工件/关机尾（不适用），**无任何可救型（离散写跳）实例** ⟹ **D1 平滑对现行残余零用途**，维持 47s 型历史可救案例的既有边界不动。

**升级条款触发（待用户裁定确认）**：修复方向=前端筛查/估计器状态面。依据三重收敛：①本判定（残余全急性不可平滑）②T2 R2 判决（九格干预全无效/est 内不可修/修复面=前端筛查或场景分门）③T2 R3（cost 门对 hover 瞬态族在线早检实证、对 route 急冻族 0 触发——route 域需状态面前置预警，Bgs 带是候选）。
