## 3. 用法

```
python3 tools/draft2verdicts.py <draft.md>              # 增量节文本 → stdout
python3 tools/draft2verdicts.py <draft.md> -o out.md    # → 文件（UTF-8）
python3 tools/draft2verdicts.py <draft.md> --selftest   # 转换+无损断言，证据 → stdout（rc: 0=PASS/2=FAIL）
可选 --chapter '## 自定章头'                            # 覆盖机械派生章头
```

- **锁声明：无锁交互**——纯本地文本转换，不触碰 SITL 主锁/侧锁（SITL_LOCK_FILE 无关），零远端写入；verdicts 正本零触碰。
- 本机口径：`python3` 别名不在 Git Bash PATH，本地以 `python`（Python 3.12.7）执行；源码为 python3 语法、shebang=python3，3090 侧可 `python3` 直跑。

## 5. 局限（如实登记）

1. **泛化未验证**：转换规则按今日草稿结构（H1+前部引用块+`##` 节+`###` N.M 子节+管道表+斜体尾注）编写并只在今日草稿上自测；对 7a83d06 等其他构形草稿未测，换稿先用 `--selftest` 验 PASS 再用。
2. **章头与出处行是仅有的合成语义面**：章头"源草稿机械转换·待主会话定稿并入"与出处行模板为生成器固定文本；如主会话不接受该措辞，用 `--chapter` 覆盖或定稿时改写（属定稿职责，非本工具代改）。
3. **粗体引导行独立成行**：正本惯例是引导行与首行内容同行（L339"- **判据链**：协议=…"）；为保行级 1:1 无损，本工具引导行独立成行、内容随下——格式微差已声明，合并属定稿动作。
4. **前部引用块"本文件"指称漂移**：前注"本文件全部为草稿…"逐字并入后，"本文件"指称在正本语境下语义漂移；生成器不改写（改写=事实加工），归主会话定稿处理。
5. **不做状态词翻译**（映射表⑤）与**不做任何 md5/commit/行号凭据生成**（红线⑤对账属上传件职责，本工具零上传）。
6. 自测样板产物中出处行的源路径为相对路径（`verdicts_draft_v526.md`，因自测 cwd=输出目录）；以绝对路径调用则出处行随之，属预期行为非缺陷。
