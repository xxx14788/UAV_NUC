## 章 1 项目概览与目标

**本章导语**：这个项目要做什么、边界在哪里、交付物是什么——先把这些钉死，后面所有战役才有评判的坐标系。

### 1.1 复现目标与系统构成

**是什么**：基于 ZJU-FAST-Lab 开源的 **Fast-Drone-250**（https://github.com/ZJU-FAST-Lab/Fast-Drone-250）复现一套 250 级机架的**纯视觉自主导航无人机**。全栈构成：VINS-Fusion 双目+IMU 视觉惯性里程计 → EGO-Planner 局部规划器 → px4ctrl 位置控制器 → PX4 v1.17.0 飞控（实机 FMU v6C）。硬件：机载 NUC（i5-1135G7/16G/200G，Ubuntu 20.04.6+ROS Noetic）+ RealSense **D435**（注意：非 D435i，无相机 IMU——10-08 定案，见章 5.1）。

**架构要点（复现时最容易搞错的三个）**：
1. **px4ctrl/规划器的 odom 直连 VINS**（`/vins_estimator/imu_propagate` 高频低延迟），不是绕 EKF2 融合；PX4 的 EKF2 始终存在但只服务自身状态机，位置环在机载电脑侧，PX4 只做姿态环（`/mavros/setpoint_raw/attitude`）。
2. **EKF2-EV 融合从未启用**（EV_CTRL=0 全历史 90+ ulog 零例外）——iris_stereo_vins 挂标准 iris airframe 不设该参数，上游 ZJU 同样不喂（上游对策=遥控触发重启；XTDrone 流派才用 EV）。这是复现第 5 天挖出的"考古级"架构事实（E1-E1 三合一考古，判决 1f57437）。
3. **vins_to_mavros 是我方 2026-06 新增件**（上游无此桥），带 HealthGate（跳变>1m 或隐含速度>5m/s 停转发）。

**复现步骤时序**（如果重来，这是正确的入门序）：环境摸底（09-26）→ 控制回路 SITL（tag v0.1）→ 规划接入+避障（tag v0.2/v0.3，到位 0.07-0.10m）→ VINS 同构闭环（tag v0.4，到位 0.034-0.278m）→ 实机地面链 → 首飞。实际走过的弯路（VINS sim 域病理、route 假盆地等）见章 3——每条都是"别人问细节能答出来"的干货。

### 1.2 纯视觉无 GPS 红线（用户 2026-09-28 裁定）

**原委**：用户原话"我们是纯视觉导航不许依赖 gps"。背景=实机 D435+VINS 架构，SITL 里 gazebo 注入的 GPS 只是流程代位——在 GPS 代位链路上精调的参数（磁配方/GPS course）对实机无迁移价值。T3 曾差点把"先飞 2m 建立 GPS course"写成修复配方，被用户纠正。
**落地**：正式入库 README §0 红线 R1-R6（commit c5f7add/48d117d）——R1 定位层验证必须 VINS 链路 / R2 GPS 代位仅流程层+标注 / R3 修复合规检查 / R4 验收口径 / R5 实机零 GPS / **R6 仿真-实机链路同构**（节点拓扑与实机 full_vins_px4 同构，差距表登记：fx 454.68/387.51、IMU 100/200Hz、外参、固件）。
**方法论价值**：这条红线避免了"在代位品上精调出一个实机用不了的系统"。后来发现的代价面也要如实记账：SITL EKF2 无 GPS 行为零数据（failsafe 触发阈值/行为对实机无代表性）——E-4 的 G-off 半支就是补这个盲的。

### 3.0 前史五案（10-01 ~ 10-07 早期战役）

#### 3.0-① route 假盆地战役

- **是什么**：route 任务（导航到 goal）中 VINS 里程计 Bas（加速度计 bias）爬坡进入"假盆地"——估计器收敛到一个自信但错误的解，到位误差 3-30m 级。这是 X 线（tag 冲刺线）的唯一堵点。
- **数字多少**：健康带到位 0.79-1.10m；假盆地成熟后 27-91m；A2 修复轮 0.633m（历史首次破 0.75 门）；假盆地成熟窗=init 后 4.3-78.7s。
- **怎么发现**：T3 D1 forensics（7 袋扇出）发现 t*=起飞爬升段（6.66-7.06s 聚类）；T2 R1 四假设全证伪（4 开关格全爆，chi2 格爆点提前 32.5s=交互证据）；解剖钉死最早病变=三角化负深度→钳深 5.0→init_replace 注入（t=42.6s 先于 cost 爆）。
- **怎么验证**：用户 10-03 深夜亲自做 **0 噪声实验**（完美 IMU 照样爆）+复验复原对账（双目 rig 与从未动过的镜像逐字节一致 974a7533）——传感器噪声线闭案；回放逐位中性排除栈差；R3x 证伪求解饥饿（21 轮 slv p95≤27ms）；T3 证伪规划器（poscmd→goal 0.013m 无罪）。
- **机理**：猛动态×障碍场景→双目匹配几何性失败→**负深度伪注入 13-28 帧/帧**→init 后脆弱窗内把 Bas 拖进爬坡假盆地；哪轮点火由异步时序运气决定（载体与噪声无关）。

### 3.4 50pp 波动案（判读方法论推论）

- **五件栈**：roscore/mavros/VINS（vins_to_mavros）/ego_planner+traj_server/px4ctrl；启动序+watch2/kill_watch 守护。
- **FC**：PX4 FMU v6C.x，固件 v1.17.0（2b 重校实证）；串口 921600。
- **相机规格**：原生双目 640×480 Y8@30Hz（infra1 29.98/infra2 29.96Hz，双目硬件同步=δ=0 结论来源）；D435 infra 原生最高 848×480 不用满（**848 组合超 USB3 控制器等时传输预算=bandwidth exceeded**，Intel 已知现象；640 组合约减半进预算）。
- **emitter 胶带定案**：on 态角点 p50=11 vs off=36（暗光域 3.3 倍优）→胶带物理贴住（VIO 优先）；代价=深度避障变被动双目（台架实测归 1f）。

### 5.2 IMU 频率案

- **50Hz 默认→203Hz**：mavros 默认 HIGHRES_IMU 50Hz（同 SITL 的 MAVLINK_MODE_ONBOARD 硬编码家族）；**MAVLink 511 命令（105=MAV_DATA_STREAM_RAW, 4000µs 间隔）→203Hz**（500Hz 请求=链路上限实测）。
- **上游实机 250Hz 对齐论证**：实机 BMI055 陀螺 ODR 2000÷8=250Hz（驱动写死）；上游标准 200Hz IMU；我们 50Hz IMU/30Hz 视觉=1.67 条/帧已偏紧——203Hz 是必要修复非过度优化。
- **时间戳抖动实测**：dt 波动 2.3-7.5ms **无害**（VINS 逐样本时间戳算 dt）；**真正进 dt 的误差=相邻延迟差：p50=0.039ms/p95=1.88ms**——抖动看差分不看绝对值，这条口径后来成了判读标准。
- **timesync 映射**：串口延迟剥离（mavros timesync 服务）。
- **"203Hz 压垮全家桶"假说否证**：静置实验全家桶仅 1.7/8 核——CPU 非瓶颈。

### 5.3 USB 断链案全链（侦探案范本）

- **症状**：场景批录制质量事故——scen1 VINS 爆 |Bas|=5.88+scen3/4 IMU 零条。
- **统计假象揭穿（第一层）**："202→129→0 渐死曲线"是**分母假象**——129Hz=断流时长被算进分母；实际=全程 203Hz 一次断链即死（无渐变）。
- **内核铁证（第二层）**：dmesg `cdc_acm ttyACM0` 重枚举 @23:09:39 与 VINS 死亡时刻**秒级吻合**——USB 物理断链。
- **机理**：mavros 无热插拔恢复（USB CDC 重枚举后 /dev/ttyACM0 句柄失效，mavros 不重连）→IMU 断流→VINS 饿死。
- **修复三件**：USB 线物理固定+新电池（供电纹波排除）+**imu_watch_recover.sh 自愈脚本**（断流检测→重启 mavros→VINS 复活）。
- **r2 重录四袋全优+昨晚 Bas 爆未复现=USB 劣化单一根因闭合**。
- **可教学性**（症状→判据→工具→坑→处方）：症状=IMU 流秒死/Bag IMU 零条→判据=dmesg cdc_acm 时间戳对齐死亡时刻→工具=dmesg -T|grep cdc_acm+imu 频率监控→坑=频率均值统计掩盖单点断链（分母假象）→处方=物理固定+自愈脚本+录制前 IMU 连续性预检。
- **如果重来**：录制批前加"IMU 连续性 30s 预检"（一条 rostopic hz 命令），能省一个晚上的事故分析。

### 5.7 内存泄漏四部曲（L0→L2）

- **发现**：VINS RSS 涨势 0.6→1.45GB/h 非平稳+odom 15→5.7Hz 劣化@9.4h+重启即复。

- **处置（终局制）**：修复=跨 VINS/Ceres/OpenCV 三层复合生命周期工程（多日量级）→**归升级路线图 W12 冻结域**；现实运维=**半小时飞行 1.1GB 安全**（2.18GB/h×0.5h≈1.1GB，16G 机余量足）+5h 窗重启制+watch2 在役续采。附:旧机 crash 史新发现=10-10 三连 crash-boot（8GB 级 VINS+桌面在 15GB 机，OOM 型 plausible）=5h 窗制再加正据。

## 章 7 判读与工程方法论（核心章）

**本章导语**：项目沉淀的可复用资产分两半——判读方法论（怎么对一个飞轮出可信结论）和多 agent 协作工程制度（怎么让四个并行会话不互相踩死）。加上证伪清单和治理决策史,这章是"老师傅经验"密度最高的地方。

### 7.1 判读方法论八条

1. **预注册先行**：判据先于数据落盘（682dc3a 先例）；判据未预注册不出 PASS/FAIL（红线①，E4 双峰实录后实操确立）——"先看数据再定判据"是自欺的入口。
2. **判据冻结零变动**：门值/口径在批中禁改；anchor 案③走 prereg §2.8 冻结+双锚上线；改判读器必带 selftest+历史轮 re-regression 零漂移验证（18 样本逐位先例）。
3. **双工具互证**：HAFIX 终验 20/20 双工具逐位；X4 双链（内嵌∧T3 影子 7/7）——**影子重跑是独立复核的正源形态**。
4. **锚点哨兵**：HVNET1 4.12（悬停终态）+BL5 三锚+列语义探针——判读工具自身用已知样本站岗（j0_end 列语义勘误就是哨兵抓的：judge 第 4 列实为 maxjump）。
5. **j0d 三列分账**：jump/transit/恒等式——"跳变"与"漂移"不分解就会互相冒充（巨跳 8 轮实为慢漂 5+真跳 3）。

### 8.4 坑账分类学（月报 131 条五大类系统呈现）

**类① bash/脚本陷阱**（代表+对冲）：
- `set -u` 在 ROS source 前杀脚本（复发 4 次，A5）→先 source 后 set -u；
- `while read` 尾行无换行吞行（112/113）→文件尾保证 LF；
- sed 分隔符与正则竖线撞车（`s|...|...|` 内含 `|`）→换逗号分隔符；
- sed 替换含 `2>&1` 时 `&` 必转义（v1_flight.sh L70 事故）；
- bash `local a="$1" b="$a/x"` 一行多赋值非左到右→拆行；
- awk POSIX ERE 无反引用（等值校验全假阳性）→grep -P 或分布核读。

**类② ssh 家族**：
- heredoc/echo 中文必乱码→本地写+scp+远端 cat（红线⑥）；
- heredoc 经 stdin 被吞（python 实际读空脚本零报错，月报#42）→两段式；
- 复合命令含 pkill 模式串→自匹配杀会话（复发 6+ 次，最高频坑）→`[x]` 字符类/-x 精确名/脚本文件化；
- 非交互 ssh 无 ROS 环境（复发 4）→bash -lc 显式 source；
- CRLF→`ssh -T "tr -d '\r'|bash"` 通道。

**类③ git 纪律**：
- 共享树 staged 裹挟（两次实锤）→commit 前 porcelain 查第一列，逐件 add 禁 add -A；
- .gitignore 吃 gtest/test 资产（复发 4）→部署前 git status --ignored 强制查；
- 远端名 UAV_NUC 非 origin→push origin 必失败；
- 3090 git 身份未配→-c user.name/email 或预配。

**类④ ROS 域**：
- 共享 roscore 双 clock/双图像串流→重放必私有 master（113xx）；
- ROS_MASTER_URI 跨命令泄漏→回放专用 master 勿泄给在线链；
- logger_topics.txt **替换语义**毁默认主题集（84KB 空壳 ulg 事故）→禁用改走参数路径；
- mavros 订阅触发流瞬时 echo 空采→持久后台流或预热窗。

**类⑤ 判读统计陷阱**：
- 显示层乱码≠文件坏→md5+hexdump 验本体；
- 分母假象（202→129→0 渐死曲线实为单点断链）→比率指标先核分母口径；

- 判读器截断浮点/字段路径假阴性→先看 3 行实物样例。

**对冲模板（跨类通用三件）**：①两段式（本地写→scp→远端执行）通杀引号/转义/中文/heredoc 四族；②退出码不信任链（管道吃 RC→远端落文件+md5 回读）；③合成正例单测先行（新判决路径必须合成正样本验证）。
