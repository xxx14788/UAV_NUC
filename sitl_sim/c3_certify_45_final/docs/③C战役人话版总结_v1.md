## 四、没做到的诚实清单

1. **S 形织行**：干净域 0——几何上单侧 C 形就是最短路，planner 理性地不织 S。48 轮里唯一 S 全门轮（S4）反而没到位。这是判据设计与物理的张力，如实呈现。
2. **综合 24.4% vs 投影 63-74% 出带**：投影是"挑过健康域+绕行门+到位全理想"的乐观乘积，前瞻批把它打回原形。教训已入 threats（预防条款：投影域筛选必须前瞻性定义）。
3. **NF 未起飞 7/48**：boot 慢投递域未根治（起飞前投递链路慢），只是如实分账。
4. **健康彩票（VINS 轮级方差）**：12 旗轮零到达=强相关，但根因在仿真渲染时戳域，未在 sim 内根治（实机九袋实测量级干净 4-5 个数量级=实飞不是这个病）。
5. **13m 层能力**：到位 0 的边界还在（尺度红线），论文里只作历史对照层。
