## 2. 主判据（设计件 §3 冻结，逐字沿袭——零变动）

- 绿率（RESULT=PASS 占有效轮比例）提升 **≥15pp** ∧ **方向一致（单绿对）≥6/8** →
  约束②a=绿率修复主件成立（有效）。
- 副指标：transit 窗 |d(Ba)/dt| 均值（约束生效性）+j0 终态/jump 面（复验批同判读链）。

## 3. 三层判读预设（任务书 v10.10 单元 2 钦定——批前补注册）

- **层① box 生效直接证据**：A 臂 |Bas| 全程被压在 ±0.5/±0.05 域内的时间占比
  （[T2diag] 逐帧行统计）——**>95% = box 物理生效**（绿率未变也证明机制工作）。
  B 臂同统计=基线越域率（漂移吸收路径的定量证据，判读材料非判据）。
- **层② transit 慢淋疗效面**：A/B 臂 transit 窗（首帧 V>0.3 m/s 起，至 V 回降
  <0.2 m/s 止——沿设计件 ②b 窗定义复用为度量窗）内 |d(Ba)/dt| 均值对比+transit
  jump 分量（jump 列）对比。机理预测=A 臂 transit 段 |Bas| 不再自由漂移。
- **层③ 失败模式预分类**（判负时按类归档，处置路径各异）：
  - **box 无效型**=A≈B 逐位同（verdict/jump 带内同）∨ A 臂 box_banner=0 →
    box 未被读取或域值过宽 → 处置=配置链审计（banner/env 通路）非机理否定；
  - **box 过紧型**=A 绿率反降 ≥15pp+Bgs/外参估计劣化征兆（tic0 漂移带外）→
    处置=域值审计转 ②b（设计件 §2 判负升级条款）；
  - 机理负型=层① 生效(>95%)但绿率/jump 无改善 → box 约束物理生效但漂移吸收非
    主导路径 → 处置=bias 路线证伪定案文书（任务书单元 3 第三分支）。

## 4. 分母不足分支（任务书 v10.10 单元 2 钦定）

E8P plain 毒域当夜断流止损致有效对 <8 → **当夜补轮至完整**（1 次重试/轮上限沿用）；
仍不足=如实注记分母数+按实有对数判读（禁以分母不足为由空转收工）；跨夜补轮禁

## 5. 干测前置门（任务书单元 1——通过才进臂批）

（N8P B=0.076）∧ banner box=0 → 通过。干测 FAIL=栈问题停批修复（非预期路径）。
