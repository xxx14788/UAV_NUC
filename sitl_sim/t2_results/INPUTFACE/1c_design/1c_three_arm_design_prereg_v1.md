## 1. 背景与实验问题

1e 输入面实锤（E8P 2/2 同刻同带复现+慢漂终态差 1-2.4% 确定性）确立：**输入面主导的跳变族存在**。但输入面内部三候选未分离：

| 候选 | 机理假说 | 实机对应物 |
|---|---|---|
| C1 标戳（时间戳配对） | 左右目时间戳错位→三角化深度错→状态跳变 | d435 硬件同步误差/td 估计偏差 |
| C2 帧节奏（渲染时序） | sim 特有：帧到达节奏/丢帧/乱序 | 无（实机 USB 带宽丢帧除外） |
| C3 帧内容（特征场景带） | E×plain 特征带（低纹理/重复纹理区）触发 | 有（场景本身） |

实验问题：**哪个候选是 E8P 跳变复现的必要条件？** 方法=受控变量回放：单因子编辑输入，观察跳变形态响应。

## 3. 三臂设计与工具

### 3.0 工具：t2_bag_editor.py v1.1

- 三模式 `retstamp`/`retiming`/`repaint`，语义已在工具头注释**冻结**（§Frozen semantics）。
- **磁盘策略（任务书强制）：参数化重生成**——编辑参数+源袋 md5 落 JSON manifest，编辑袋**用后即删**，禁 13G×N 常驻副本；重生成=`--from-manifest`（指纹+md5 双校验，源袋漂移拒跑）。
- **dry-run 先行**：任何编辑袋生成前必跑 dry-run（域检查+窗内帧数+参数校验）；域检查 FAIL（header-vs-bag 偏移 >600s 跨域分裂）=硬拒（T2b 毒槽位教训）。
- 时间窗一律用**相对秒**（从袋首起算），禁绝对戳。

### 3.1 臂 A：标戳重写（→C1）

- 变换：右目 header.stamp := 最近邻左目 stamp + δ。
- 梯度系列（预注册，禁跑后增删）：**δ ∈ {0(=align same), ±2, ±5, ±10, ±20} ms**，共 6 点（含 0 点对齐）。
- 材料臂：M-A 全套 6 点；M-B 只跑 {0, ±10} 3 点（悬停标本为辅助对照）。
- **副产物（任务书联动条款）**：跳变形态 vs δ 曲线 = **td 敏感性曲线**，输出给 T1 1a 时间戳核查作解读框架（实机 td 标定预警阈值依据）。

### 3.2 臂 B：帧节奏变换（→C2）

- 四操作（各一轮，M-A）：
  - `drop-periodic drop-every=3`（丢 1/3 帧）
  - `drop-random drop-frac=0.10 seed=7`
  - `downfreq target-hz=15`
  - `reorder swap-window=2`
- 语义注记：reorder 只交换 header.stamp（bag time 播放节奏不变）——测的是"VINS 可见的时序错乱"；drop/downfreq 是真丢帧。
- C2 为 sim 特有候选：**若全无作用 → "实机无忧"注记成立**（任务书原文语义）。

### 3.3 臂 C：帧内容替换（→C3）

- 变换：矩形区域涂抹（repaint），双目同区域同帧窗。
- 参数：区域=中央 60%×60%（0.2,0.2,0.6,0.6）+ 全图（0,0,1,1）两档；mode=black；窗=**跳变时刻 ±2s**（baseline 重放定位的跳变带，执行时从 baseline 结果抄录并冻结在本件附表）。
- 材料：M-A（M-B 悬停标本不涂——无跳变可消）。
- **联动条款**：若臂 C 消除复现 → **场景改造新修复面立项**（比输入门更根本——改 world/纹理而非事后过滤）。

## 4. 判据预注册（冻结，跑后禁改）

### 4.0 前置：跳变复现（baseline 与标本有效性）

- **复现** = baseline 重放的 j0 终态漂移 ≥1m（与 1e 实锤口径同族）且跳变时刻落在标本原跳变带 ±5s 内。
- 不可复现 → 标本作废+登记，换备用标本或如实收窄。

### 4.1 主判据（任务书操作化定义，逐字冻结）

- **"消除"** = 跳变不复现：j0 终态 **<1m**。
- **"改变形态"** = 跳变时刻偏移 **>2s** 或幅值变化 **>30%**。
- **命中归因**：哪个单因子变换产生"消除"或"改变形态"= 该候选实锤（消除=强实锤，改变形态=弱实锤）。
- **三臂全无作用**（全部变换下复现形态在 4.1 阈值内不变）= 回到"估计器内部独大"收窄。

### 4.2 度量口径

- j0 = 终态漂移（jump_prepost 口径勘误后的**终态漂移语义**，非单帧跳变幅值——C.10 债教训：文书禁混读）。
- 幅值=odom 位置范数最大帧间变化；时刻=该帧相对袋首秒。
- 每臂输出：j0 终态 / 跳变时刻 / 幅值 / VINS 存活 / cost 面摘要（t2_dissect 复用）。

### 4.3 次级观察（不判 PASS/FAIL，只登记）

- 臂 A：|δ| 单调性（形态响应是否随 δ 梯度单调）→ td 敏感性曲线形状。
- 编辑器自身健康：mono-viol 计数（retstamp/repaint 必须=0，违者该轮作废重跑）、域检查、每轮 manifest 指纹登记。

### 4.4 样本量与重复

- 每个有效（臂×δ/操作/区域）组合 **≥2 次重放重复**（回放非确定性已知——1e 慢漂终态差 1-2.4%——重复取一致方向才算数：两重复结论方向不一致=该组合"混合"，登记不硬判）。
- 预算：M-A 6(A)+4(B)+2(C) =12 组合 ×2 =24 轮重放 +M-B 3×2=6 +baseline 2×2=4 ≈ **34 轮重放**（每轮≈袋时长，串行）。
