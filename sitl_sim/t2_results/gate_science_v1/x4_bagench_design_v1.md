# 1e 带图裁决设计件 v1.0（T2 v10.1 单元 4；启动条件已触发：定因四排除全排除支）

> 目的：判别 H5 两支——估计器内部（运行时面）vs 输入面（观测面）。
> 前置事实：X5 紧凑袋零图像 → 1e 判决"材料不可行"在册（EX-FAIL 第五坑同族）；
> 前瞻修=X4 批带图 ≤2 轮=首批可回放标本（T1 v11.18 C-1 在册）。
> 本设计=T2 册任务（预注册稿，供 T1 X4 批编排消费）。

## 1. 设计原理

跳变若源于**输入面**（图像/深度内容坏脉冲）→ 同输入回放必然复现（确定性重放）；
跳变若源于**运行时面**（时序/竞态/调度等进程内非确定性）→ 同输入回放不复现或形态漂移。
（在册先例：ζ 双稳态回放复现率 3 次稳定 / MACH8 bias-lock 回放复现=输入确定性——
回放域方法论已成熟，shift bag+dt 钳制配方在册。）

## 2. 选格（预注册）

- **格 1 = E8P**（plain 世界，8m 东向）：X5 批 3 轮全部巨跳（40.6/30.4/26.0m），
  跳变发生率 3/3 全库最高——最快取证格；且 2/3 轮属"前兆可测型"（cost surge 提前 40s+），
  双保险：即便不跳，前兆签名也可判读。
- **格 2 = 悬停型 HVNET1 复刻**（物理静止×自跳 2.985m 在册）：剥离机动/视差变量——
  悬停也跳则输入面嫌疑集中于场景静态内容；悬停不跳而 E8P 跳则机动交互回到主嫌。
- 预算：带图 13.9G/轮 ×2 ≈ 28G（df 568G 充裕）。

## 3. 判别判据（预注册，先于飞行冻结）

设带图轮 R 发生跳变（10Hz diag |ΔP|>1m 或双锚 pre-post>0.5m）：

| 回放结果 | 判决 | 证据强度 |
|---|---|---|
| 同输入回放 ≥2 次均复现跳变（同时刻±2s 或同里程±5%） | **输入面实锤** | 强（确定性复现） |
| 回放 0/2 复现，在线原轮跳变 | **运行时面实锤**（进程内非确定性） | 强（同输入不跳=输入无罪推定） |
| 1/2 复现或形态漂移（跳幅差>3×） | 混合型 | 中（加放第 3 次判多数） |
| 带图轮本身不跳 | 无事件（如实登记，不烧重试） | — |

- 回放栈口径：streamguard v4 当前 devel（起飞前双 md5 实读）+ 私有 master + shift bag
  配方（在册）；回放窗=全程（init→降落）。
- 复现判定用双指标：跳变时刻对齐 + 跳幅量级带。
- **判据门值不因结果放宽**（红线 24）。

## 4. 分支行动（判据→下游，预注册）

- 输入面实锤 → 前端筛查修复面立项（图像/深度质量门=纯脚本面可落 X4 后）；sim 域特有
  候选（渲染时序/双目标戳微差）升格主嫌 → 与上游 case2 对照注记收口。
- 运行时面实锤 → 估计器内部非确定性取证（G1 strace 预备稿启用面）→ 修复面=调度/锁
  域（写码立项，tag 后）。
- 混合型 → 两面各记一票，X7 §8 如实条目。
- 无事件 → 标本价值=带图袋本身（后续任意回放素材），1e 判决推进依赖 X4 后续批。
