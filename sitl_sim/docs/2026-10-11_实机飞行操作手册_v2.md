## 1. 谁在控制谁——开关语义与状态机

链路三行：D435+IMU → VINS 定位（`/vins_estimator/imu_propagate`）→ 规划器吃 goal 出 `/position_cmd` → px4ctrl 发姿态/油门 → PX4。位置环在 px4ctrl 板上（`use_px4_position_ctrl: false`，用户裁定 B 支），PX4 端只执行姿态。

**px4ctrl 状态机**：`MANUAL_CTRL ⇄ AUTO_HOVER ⇄ CMD_CTRL`（另有 AUTO_TAKEOFF/AUTO_LAND，§2.7）。源码 `px4ctrl/src/input.cpp:38-94` + `PX4CtrlFSM.cpp`。

| 通道 | 语义（实机源码，两态阈值开关） | 你要记住的 |
|---|---|---|
| **CH5**（mode） | 低=MANUAL_CTRL（PX4 姿态手控）；高=AUTO_HOVER（px4ctrl 吃 VINS 定点悬停） | **拨低=终极接管**，任何时候立即回到你手里 |
| **CH6**（gear） | 仅 hover 态生效：高=CMD_CTRL（跟踪规划轨迹）；低=退回 AUTO_HOVER | 自主飞行中**拨低=立刻停跟轨迹、原地悬停** |
| **CH8**（reboot） | MANUAL 态下从低拨高=**触发 PX4 飞控重启** | ⚠️ 危险开关，飞行全程勿碰 |

- 自主中想收回：先 CH6 拨低（悬停），要动手再 CH5 拨低。hover 态下摇杆可微调机位，限速 `max_manual_vel: 1.0` m/s。
- px4ctrl 自保护：odom/RC/cmd/IMU/电池**任一断流 >0.5s 即退出当前模式**；FCU 状态流断 >3s 且未解锁→FSM 重置。
- 进 hover 被拒时（px4ctrl 终端 ERROR 行）别反复拨开关：`L2`=无 odom、`P1`=odom 重生错位、`P2`=cmd 响应背离闩——按 §7.1 重启 VINS 再试。
- **现场确认件①**：px4ctrl 首次启动会提示 RC 校准（按提示拨 CH5/CH6 到指定位置确认，自动保存）。校准时实测三通道"哪边是高/低"，回填附录 B。方向实测与上表不符时，以实测为准并回填。

## 2. 每次飞行 SOP（命令 + 判定线）

### 2.1 上电
遥控器 → 电池（实测满电≈15.9V）→ NUC。注意：**未插电池时 FC 走 USB 供电，电池读数恒 0.0V**——这是预检 FAIL 的已知假信号，插上后复跑即消（unit2b 复测表）。

### 2.2 起主栈（NUC 上，约 1 分钟）
```bash
ssh nuc
bash ~/sitl_realmachine/realmachine_2a_reboot_stack.sh
```
脚本自动起五件并自检四流：mavros connected / IMU ~50Hz / infra1 ~30Hz / VINS `imu_propagate` 出流，末尾打印五进程 pid 行。日志落 `~/sitl_realmachine/09_reboot_stack_2026-10-09/`（`vins_<TS>.log` 后面要用）。**脚本不含规划器**，下一步单独起。

### 2.3 depth 流验证（每次栈起必做）
D435 有 Asic 边界态病史（启动期 hwmon 报错，断电复位救回过一次）：
```bash
rostopic hz /camera/aligned_depth_to_color/image_raw     # 期望 ~30Hz
```
0Hz → D435 断电复位 → 重跑 2a。规划器避障地图吃的就是这条流，不过不过飞。

### 2.4 起规划器（另开终端）
```bash
source /opt/ros/noetic/setup.bash && source ~/catkin_ws/devel/setup.bash
roslaunch plan_manage run_planner_realmachine_vins.launch
```
（env 必须先 source：非交互 shell 无环境会静默失败，本项目实锤过。）

### 2.5 预检（六项，输出 GO / NO-GO）
```bash
python3 ~/sitl_realmachine/tools/t1_preflight_check_v1.py \
  --vins-log $(ls -t ~/sitl_realmachine/09_reboot_stack_2026-10-09/vins_*.log | head -1)
```
| 项 | 判据 | 不过怎么办 |
|---|---|---|
| CAL_GYRO0 X/Y/ZOFF | \|v\| ≤ 0.005 | 重做陀螺校准 |
| CAL_ACC0（注记项，不设门） | 脚本基准是重校前旧值，**恒会提示"重标定"=已知项**；人工对照新基准 -0.2409/+0.2808/+0.2214（unit2b 复测表） | 目检即可 |
| odom 流 | ≥5Hz 且数值全有限 | §7 排障 |
| 电池 | ≥14.0V | 0.0V=没插电池；低=换电 |
| mavros 链路 | connected=True | 查 USB/FC，§7 |
| VINS 病理带 | 120s 窗内 \|Bas\| 中位 ≤0.8 且 cost 中位 ≤1e4 | 重启 VINS 复跑 |

`PREFLIGHT GO` 才继续。NO-GO 逐项按上表处理。

### 2.6 现场确认件②：PX4 failsafe 参数（首飞窗必须落值，§9.2）

### 2.7 起飞与降落三式
**A. 手动起飞（首飞用这个）**：CH5 低=PX4 手控，解锁起飞至 **1.2m** 手动悬停 → CH5 拨高=px4ctrl 定点悬停（稳=VINS 健康）→ CH6 拨高=交给规划器。

**B. px4ctrl 自起飞**（配置已开 `auto_takeoff_land.enable`，含自动解锁，爬到 0.75m，0.5m/s）：
```bash
rostopic pub -1 /px4ctrl/takeoff_land quadrotor_msgs/TakeoffLand "{takeoff_land_cmd: 1}"   # TAKEOFF
```
未实机验证过，首飞后启用；自动解锁路径第一次使用时手不离 CH5。

**C. 降落**：手动降（推荐：CH6 低→CH5 低→缓降触地）。或 px4ctrl 自降（0.5m/s 缓降）：
```bash
# ⚠️ 彩排发现（rehearsal_004513 N6）：CH6 高/planner 在流（position_cmd 持续 100Hz）时
#    LAND 命令被 fsm 决策表消费不评估=静默无效。发 LAND 前必须：先 CH6 拨低（等 1-2s），
#    或先停 planner：bash ~/sitl_sim/kill_planner_all.sh
rostopic pub -1 /px4ctrl/takeoff_land quadrotor_msgs/TakeoffLand "{takeoff_land_cmd: 2}"   # LAND
```
**不存在"发低 goal 让它降"**——单点 goal 的 z 被硬编码为 1.0m（§0），v1 那条是错的。

### 2.8 落地收尾
disarm → `docs/flight_log.md` 追加一行（格式在文件头）→ bag 归档（§8）。VINS 重启按需（§7.1）。

## 4. 我要它怎么飞——goal 与航线

### 4.1 坐标系
原点=**本次 VINS 初始化位置**（栈起后首次定位成功点），x≈机头朝向，y 左，z 上，单位米。**重启 VINS=原点重锚，之前记的坐标全部作废**。

### 4.2 单点 goal（真实语义，与 v1 不同）
```bash
rostopic pub -1 /move_base_simple/goal geometry_msgs/PoseStamped \
  '{header: {frame_id: "world"}, pose: {position: {x: 2.0, y: 1.0, z: 1.0}}}'
```
- **生效的只有 x/y**；z 恒为 1.0m（FSM 硬编码），orientation 完全不消费。
- RViz 2D Nav Goal 发同话题，**拖拽方向不定朝向**，效果与 CLI 相同；RViz 主要用来可视化 odom 轨迹和目标点（`rviz -d ~/catkin_ws/src/planner/plan_manage/launch/default.rviz`，需显示环境）。
- 发出后规划器立刻规划，飞机到点悬停等下一个 goal 或 CH6 拨低。
- **goal 时序纪律（彩排 N5 发现）**：严格"到点悬停→再发下一 goal"——未到点连发不生效（SITL 实测；vins_smoke leg2 到点后发=几百轮已证正路）。
- 返航：发 `(0, 0)` 即回起飞点上空 1.0m 悬停，再手动降。

### 4.3 航线模式（唯一可指定高度与多点的入口，不改代码）
编辑 `run_planner_realmachine_vins.launch` 三处后重启规划器：
```xml
<arg name="flight_type" value="2" />      <!-- 1=单点手动, 2=预设航线 -->
<arg name="point_num"  value="3" />       <!-- 航点数 -->
<arg name="point0_x" value="2.0" /> <arg name="point0_y" value="0.0" /> <arg name="point0_z" value="1.0" />
<!-- point1..N-1 同格式；这里的 z 是真实生效的 -->
```
起飞→CH6 拨高后自动按序飞完全部点；CH6 拨低随时中止。航线 z 上限留 0.5m 裕度（≤2.5m，地图顶 3.0m）。

### 4.4 速度/加速度/前瞻
同在 launch 里：`max_vel=0.5`（当前保守起步值）、`max_acc=6.0`、`planning_horizon=6`。改后**重启规划器**生效。放宽速度一档一档来（0.5→1.0→1.5），每档至少一轮完整验证并留 flight_log——本机 max_acc 6.0 偏大，速度放宽时观察超调。

## 6. 紧急处置

**HAFIX 安全链（在役、缺省开，编译于 px4ctrl 修复版 89dc2a1）**：飞行中 odom 死亡→梯① watch（odom 断 5.0s，fsm_decision.h `dead_s`）→AUTO_LAND（冻结 odom 的 z 设点缓降）→梯② 若 dead_s+kill_s=20s 后**仍在空中**则发 185 FLIGHTTERM（终止飞行）→梯③ 落地即发 400(0,21196) forced disarm（P-2 修订：盲降触地即 disarm，不等 KILL）。终验 S1-S3 全 15/15 PASS（修复前 0/15）。表现=**飞机自己缓降、落地自锁——这是保护，不是失控**，让它完成，落地后查 VINS log（§7）。
**命令号勘正（89dc2a1，2026-10-11）**：修复前梯②③ 发的 400(1.0)/179 是错号（ARM 请求+SET_HOME，均无电机效果=假 kill）；修复后 185/400(0,21196) 真身。**400(0,21196) 空中 forced disarm 实测可用**（SITL 悬停正控 45/45 解锁成功；实机 FMU v6C unarmed 握手 ACCEPTED，2026-10-12 预验）——但**这是最后手段**（空中断电机=坠落），日常止步于 CH5 接管与 HAFIX 自动缓降。185 在 unarmed 地面态=TEMPORARILY_REJECTED（实机预验），生效域=armed 态。**端到端时序实证（彩排 0.95m 场景）**：杀 VINS→~7-11s 开始自动缓降→~16s 触地→~21s 自锁 disarm，全程别抢；详见《异常应对时序记录》（3090 `~/sitl_sim/t1_evidence/preflight_boost_20261011/abnormal_response_timeline.md`）。

| 情况 | 动作 |
|---|---|
| 任何不对劲 | **CH5 拨低**=立即手控，压杆稳住，降落 |
| 自主中要中止任务 | CH6 拨低=原地悬停，再决定手动降或继续 |
| 发 LAND 命令没反应 | **CH6 高/planner 在流时 LAND 被 fsm 决策表消费不评估**（彩排 N6 实证）——先 CH6 拨低等 1-2s 或停 planner 再发 |
| 飞机自己缓降/落地自锁 | HAFIX 在干活，别抢；落地后按 §7 查 |
| dashboard 单帧跳变红色（>0.5m）+飞机看似正常 | VINS 毒帧（odom_gate 会拒帧，真值不受污染）——**立即 CH6 拨低收短任务，择机降落重启 VINS**；若伴随肉眼漂移=CH5 接管 |
| 快速漂走/姿态乱 | CH5 拨低就近落地，宁摔勿飞 |
| 电池 13.2V 告警 | 立即手动降落 |
| 电机异响 | CH5 拨低，就近落地 |
| 遥控器失联 | **行为未定案**——取决于 PX4 failsafe 参数（§9.2 现场件落值）。落值确认前不得飞出回收半径 |

## 7. 排障决策表（本机脾气）

| 症状 | 根因 | 动作 |
|---|---|---|
| preflight 电池=0.0V | 未插电池（FC USB 供电） | 插电池复跑 |
| depth 流 0Hz | D435 Asic 边界态 | 相机断电复位→重跑 2a（§2.3） |

| 改了参数没生效 | 改错文件 / 没重启对应节点 | 对照 §5 "改后动作"列 |

## 9. 首飞窗专项（预授权链现场件）

### 9.1 链条
动力套修复 → **最小动力验证**（用户在场 ≈30min：地面怠速观察电机/电调响应 + 急停拨测=CH5 拨低立即断自主路径，PASS 判据=响应即时无异响）→ 电池净面（插电池后 preflight 复跑=GO）→ 首飞窗。

### 9.2 现场件②：PX4 failsafe 参数逐条落值
查询逐条执行、结果填回 `~/sitl_realmachine/04_safety_chain_remote/failsafe_params_*.txt`（当前为空模板=未落值）：
```bash
rosrun mavros mavparam get NAV_RCL_ACT
```
十五项：`COM_RCL_EXCEPT / COM_RCL_ACT / COM_RCL_LOSS_T / NAV_DLL_ACT / NAV_RCL_ACT / COM_OBL_RC_ACT / COM_OBL_ACT / COM_LOW_BAT_ACT / COM_ARM_WO_GPS / NAV_GPSF_RTL / COM_POSFS_ERR / COM_VELOFS_ERR / COM_ARM_EKF_HGT / COM_ARM_EKF_POS / CBRK_VELPOS_ERR`。
本项目约束下的取值原则：**失联动作（NAV_RCL_ACT/COM_OBL_RC_ACT）选 Land 系而非 Hold 系**（PX4 端水平位置参考薄弱，Hold 不可靠）；`COM_ARM_WO_GPS` 必须允许无 GPS 解锁（纯视觉架构）；`COM_LOW_BAT_ACT` 与 §0 电压线对齐。落值后首飞前复核一遍。

### 9.3 现场件③：本手册命令逐条过一遍
planner 起法（§2.4）/ goal 语义（§4.2）/ takeoff_land 话题（§2.7）/ VINS 重启（§7.1）——在地面栈上空跑一遍确认无路径错误。

### 9.4 首飞剖面（planner 执行面首验安排在内）
1. **第 1 飞**：手动起飞 1.2m → CH5 高 hover 定点 30–60s → 手动降。**不设 goal**；
2. **第 2 飞**：hover → CH6 开 → 单 goal（前方 2m，自动 1.0m）→ 到点悬停 → goal (0,0) 返航 → 手动降。这一飞=planner 执行面（goal→position_cmd→实飞）实机首验；
3. 之后：航线模式（§4.3）2-3 点短航线 → 放宽距离 → 放宽速度（§4.4）。每轮 flight_log 留痕。

## §10 飞后规程（v2.1 新增；降落→归位全程，顺序勿乱）

1. **落地即 disarm**（手动 disarm 或确认 HAFIX 梯③已自动 disarm——dashboard armed=False）。
2. **停栈顺序（先停消费者后停源，防 HAFIX 误触发）**：
   ```bash
   # ① 先停规划器（停吃 odom 的第一个消费者）
   bash ~/sitl_sim/kill_planner_all.sh          # traj_server+ego_planner（3090/旧机同名）
   # ② 再停 px4ctrl（HAFIX 宿主；停它之前 planner 必须先停，否则
   #    position_cmd 断流可能被误判——虽然 cmd 断流只退 CMD_CTRL 不触发 HAFIX，保守序）
   pkill -f px4ctrl_node
   # ③ 最后停 VINS 与 mavros（数据源；FC 侧无依赖可随时停）
   pkill -x vins_node
   ```
   **VINS 停前先确认录袋已停**（步骤 3），防漏录尾段。
3. **数据保存（人在撤场前完成）**：
   - dashboard csv：`/tmp/flight_monitor_*.csv` → 拷入 `~/sitl_realmachine/` 当日目录；
   - 首飞袋：`~/sitl_realmachine/bags/firstflight_*.bag`（r 键或 ff_record.sh 已停）；
   - flight_log.md 追加一行（§2.8）。
4. **迁移 3090（旧机磁盘 28G 级，飞后即迁）**：
   ```bash
   bash ~/sitl_realmachine/tools/ff_bag_migrate.sh    # md5 双端一致才删源
   ```
5. **ulog 取数（FC 侧复盘数据，当天完成）**：SD 卡自动录（SDLOG_MODE=0，arm 即录）；经 mavros ftp 拉取（附录 C 尾部 SOP）或 QGC Log Download。
6. **VINS 重启归位（为下一飞做准备，或直接收工）**：按 §7.1 规程重启 VINS（地面态）；若当日收工，停 mavros+roscore，NUC 可保持上电（kill_watch 自启在役）。
