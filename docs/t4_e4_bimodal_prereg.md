## 2. 双峰形态判据（三条件同时成立才立"双峰"命名，逐袋检验）

1. **BIC 差**：2-GMM（纯 numpy EM，k-means++ 初值×5 取最优对数似然）对 1-GMM 的
   BIC 差 > 10。
2. **双峰系数**：bimodality coefficient > 0.555（点估计；bootstrap 95% CI 作三级证据随文报出）。
3. **分量分离度**：2-GMM 两分量均值比 ≥ 1.5（防"微肩部"误判双峰）。

切点=两分量后验 0.5 交点；切点 ±20% 重切扫描，**分型结论对切点稳健才有效**，
否则该袋降级注记"切点敏感·形态存疑"。

## 3. 袋级分型映射（预注册）

| 型 | 判据（stereo_pool 域） |
|---|---|
| 低位健康型 | 全袋 p90 < 10px |
| 两簇分离型 | 高位簇帧占比 ≤ 0.2 且 p50/p90 < 0.1 |
| 混合型 | 高位簇帧占比 0.2–0.5 |
| 高位主体型 | 高位簇帧占比 ≥ 0.5 |

（高位簇=残差 > 切点的帧集合；占比=高位簇帧数/袋内有效帧总数。）

## 4. 判决输出映射（预注册）

1. **逐袋分型表**：六袋逐袋出型（含三条件统计量+切点+占比）。
2. **双峰判语**（形态判，非验收判）：≥4 袋非健康型且其中 ≥2 袋两簇分离型
   → "立体残差双峰形态成立（sim 域）"；否则按实际分布如实表述并给出与预注册条件的差值。
   判语不使用"通过/不通过"验收语——E4 的验收映射归 runbook §6 正源列与 P3 包（跨域对照定）。
3. **55–64s 载体窗对账（@T2 采信）**：高位簇帧落入 [55,64]s 窗的比例（覆盖率）+
   Jaccard（高位簇帧集合 ∩ 窗帧集合）/（∪），以袋内共同帧时刻栅格计，逐袋报告；
   逐袋残差 60s 分箱时序随文。**解释边界预声明：时间重叠 ≠ 因果**——本对账只量化
   "高位主体/高位簇与 R2 载体场景段（55–64s+，×0.1m 基线观测不一致）的共现度"，
   因果归 T2 插桩域。
