## 2. U3PO 到位 4.436m 误差分解（任务书点名项）

- **规划段（poscmd→goal）min=0.019m** —— planner 把轨迹终点贴到 goal 2cm 内，**规划域无罪**。
- **执行段（truth→cmd 同刻跟踪）p50=4.873m / p95=6.072m** —— 全部误差来源。
- 机理：闭环在 odom 系内收敛（px4ctrl 视角跟踪良好），odom 漂移 2.5-3.6m 使真值系恒差
  ~4.9m"伴飞"；truth→goal min=4.070m@94.5s（本表无锚口径；T2 报 4.436m=round_result
  锚移口径，goal 平移到 odom 系锚——两口径差 ≈|锚|投影，登记不改 T2 数）。
- **X 线差值解读框架**：到位误差先分解（poscmd→goal / truth→cmd）——若规划段 ≈0 而
  执行段大 → odom 漂移下游（R3 域）；若规划段也大 → planner 本域问题（回挖分支 3）。
