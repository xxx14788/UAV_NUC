## 1. sim_stereo vs realsense_d435 差异逐项表

| 维度 | sim_stereo(仿真) | realsense_stereo(实机) | 影响/对策 |
|---|---|---|---|
| 分辨率/帧率 | 640×480@~20Hz(渲染管线封顶 22-24Hz,E18 实测) | **640×480@30Hz**(D435 双目红外;T4-J3 E1 两方锁 2026-09-30 勘误:旧文 848×480 为 D435 全宽能力口径,NUC 实读 rs_camera_vins.launch infra/depth 均为 640×480) | 实机帧率更高、时间采样更密;特征参数(max_cnt/min_dist)按 T2b-E16 结论复验 |
| 内参来源 | gazebo camera_info(fx=467.74 已核) | D435 出厂标定+自标定复验 | 上电第一步读 camera_info 与 yaml 对账,偏差>1px 拒飞 |
| 视场(FOV, T4-J3 E2 2026-09-30) | 68.75°H/54.32°V(SDF hfov 1.2rad+yaml fx 467.74 换算,立体角 1.042sr) | 79.10°H/63.54°V(yaml fx 387.51 换算,立体角 1.368sr;全宽口径规格 87°×58°/1.361sr) | sim 视场窄 13.1%H/14.5%V;fx 比 1.2071=迁移尺度一阶风险(实机经验反推 sim 深度偏差 ~+21%);总立体角实体差在纵横比重分配(详见 docs/t4_j3_e1e2_evidence.md) |
| 外参 | SDF 刚体链可精确推导(**当前配置为手推 hack,见 T2-v3 W1 章头号根因候选——实机前必须实测标定**) | 实测(CAD+手眼标定) | 实机 extrinsic 误差对竖直机动杀伤大(E12/E13),标定优先保 z/pitch/roll |
| IMU | 仿真理想噪声(远小于配置假设) | 实机振动+温漂 | acc_n/gyr_n 按实机 Allen 方差重标;E15 网格证明该参数面不敏感(容错大) |
| 同步 | 同源 sim 时钟,无真实 td(域配方保证) | D435 硬同步或软件时戳 | td 上电自检(见 §2);E07 证明 ±40ms 内不敏感 |
| 曝光/纹理 | 无曝光变化、纹理偏少(R6 边界) | 自动曝光突变、真实纹理 | 见 §4 风险清单 |
| 出生点 | world 固定 (1.01,0.98,0.104) | 上电位姿=原点 | 一切 VINS-vs-外部真值对比必须先对齐(T2b U9 教训) |

## 2. 上电自检清单(复用既有工具,全绿才放飞)

1. **域检查**:`t2_dump_stamps.py` 等价物——双目戳与 IMU 戳同域(实机=
   同一 ROS 时钟;差 >1s 即熔断,域卫士 `t2_domain_guard.py` 常驻)
2. **频率门**:双目 ≥15Hz、IMU ≥100Hz(`t2_preflight_check.py`,阈值
   rosparam 化;实机按 D435 30Hz/IMU 实际调整)
3. **VINS init 门**:地面静置 init(门控通过标准=gate_test;**移动中
   re-init 当前 0/5 成功,T2-v3 W1 章已知短板——实机首飞必须地面 init
   后才起飞**)
4. **静态质量门**:init 后静置 10s,对齐后位移 std <5mm、twist p95
   <0.05m/s(悬停轮 0.8mm 基线;5mm 为实机振动环境放宽线)
5. **vision_pose 门控状态**:跳变门(W4)启用;IMU 一致性门(U5)**保持
   关闭**直至 v2 改造+三工况零误报回归通过(T2-v3 W1.1 实测误报记录)
6. 发布端有界性防线(estimator 补丁)在构建中:启动日志确认二进制版本

## 3. 分阶段放飞(每阶段 go/no-go 数值门)

| 阶段 | 内容 | go/no-go |
|---|---|---|
| S0 系留 | 系留悬停 30s(VINS 直供 px4ctrl) | 在线对齐 ATE@30s <0.3m;漂移率 <0.1m/min(悬停轮 0.000 基线);无 failure/无门控拦截 |
| S1 释放悬停 | 解系留悬停 30s | 同 S0;另加:twist p95 <0.3m/s |
| S2 短航线 | 2m 直线往返(两段式协议) | 到位(真值口径,实机用动捕/RTK 参考或卷尺标记点)<0.5m 连续 3s;航段 ATE <0.3m@60s |
| S3 返航 | 飞至 4m 外返回原点 | 同 S2;返程腿=两段式主协议验收段(T3-W12 返程顽疾未根治前实机返航须保守半径) |
| S4 扩展 | 逐步放大半径/加入偏航机动 | 每步全过才进;任一阶段失败→降级回上一阶段+记录 |

每阶段全程 bag 录制(双目+IMU+VINS 输出+vision_pose+px4ctrl 状态+真值
参考),**磁盘预算先行**(实机 bag 体积按 sim 5G/70s 估算提前规划)。

## 4. 风险清单

| 风险 | 机制 | 兜底 |
|---|---|---|
| 曝光突变 | 自动曝光在明暗过渡瞬间整帧亮度跳变→特征跟丢 | D435 锁定曝光(manual);VINS 侧 failureDetection+发布端防线兜底;S2 起每阶段含一次明暗过渡测试 |
| 振动 | 高频振动→IMU 噪声谱与假设失配+运动模糊 | 减震垫;acc_n/gyr_n 重标(§1);悬停轮先验证 |
| 磁干扰 | 纯视觉下 yaw 参考仅来自 VINS(磁力计不参与定位链) | yaw 漂移监控(vins_ate_eval 口径,<5°);VINS yaw 长期漂移是已知纯视觉弱点,短航线+S4 渐进暴露 |
| 运动瞬态发散 | T2-v3 W1 核心发现:瞬态(起飞/加速)非确定发散,头号候选=外参先验误差 | **根治前不放飞**:实机外参精确标定+ext 策略复核;瞬态失败 5 例全记录在案 |
| 移动中 re-init 失败 | 当前 0/5 | 流程级:任何 VINS 失效=立即降落(不悬停等待 re-init);实机遥控手接管演练 |
| EKF2 EV 融合 | EV 失流后位置控制劣化(w2b z 飙 3.8m 实测) | PX4 EV 超时参数与降级策略实机前评审(与 T1) |

## 5. 版本基线

- 二进制:含 U1 dt 钳制/W4 init 门+failureDetection/栈防护/发布端防线

  标定除外——标定结果按 README §3 登记流程入库)
