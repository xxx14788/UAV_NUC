# 纯视觉架构场景验收协议(T2-v3 W3,2026-09-28)

> 适用:README §0 R1-R6 纯视觉(VINS 唯一位置源)架构下的所有场景验收
> (T3 场景矩阵 X2/X3、五连飞 X4、T2 W1/W2)。替代旧 GPS 代位语义。

## 0. 总原则

- **双口径强制**(方法论红线):一切在线实验同时记录 VINS 自报口径与
  gazebo 真值口径;真值口径为主判,VINS 口径为自洽性指标
- **坐标系约定**:VINS/EKF2 同以出生点为原点(实测出生点 (+1.01,+0.98,
  0.104),每次会话由 GT 首帧标定);goal 语义在飞行系发布;真值口径
  一律先做 SE(2)+z 平移对齐再算距离(教训:未对齐的"恒值 1.4m 误差"
  曾误判为 VINS 漂移)
- bag 必录话题(最小集):双目 image_raw、/mavros/imu/data_raw、
  /vins_estimator/{odometry,imu_propagate}、/mavros/vision_pose/pose、
  /mavros/local_position/odom、/position_cmd、/move_base_simple/goal、
  /gazebo/model_states、/px4ctrl/takeoff_land

## 1. 到位精度(双轨定义)

| 口径 | 计算 | 用途 |
|---|---|---|
| **真值口径(主判)** | 对齐后 gazebo 真值到 goal+(出生点平移) 的最小距离;到位=连续 3s <0.5m | 验收判定 |
| VINS 自报口径 | VINS odom 到 goal 的最小距离(飞行系内自洽) | 自洽性/漂移监测;与真值口径之差 = VINS 该段的累积漂移量化 |

记录:min_d(双口径)、到位耗时、悬停保持段 RMS(双口径)。

## 2. 位置源在线质量(每轮必测)

- 对齐后 ATE@60s(<0.3m,W1 验收值)与全程 RMSE
- 漂移率(m/min,对齐后,排除 init 残差)
- init:门控通过(estimator init 质量门+vins_to_mavros 跳变门),无
  failure reboot;init 耗时
- 发散定义:对齐后误差 >1.0m 持续 ≥5 帧(vins_ate_eval 口径)
- **已知短板(2026-09-28 W1/W2 实测,解除前验收注记)**:①运动瞬态
  (起飞爬升/goal 加速)VINS 非确定发散(5 例,悬停/静态零发散;根因
  头号候选=外参先验误差,见 t2_experiments T2-v3 章);②移动中
  re-init 0/5——VINS 失效即终止该轮(不等待空中重收敛)
- 基线参考:悬停轮 RMSE 0.060m/漂移 0.000m/min;航线成功腿到位
  0.354m(EKF2 口径)

## 3. 传送/重定位语义(②⑤ 解锁)

**实机无传送操作。返程腿实机语义 = 两段式协议**(上电于 A → 飞至 B →
(新会话/重定位后)返回 A),T3 `two_leg_flight.sh` 已实现。

- **两段式 = 主协议**:段1 起飞点建图飞行;段2 返程(位置源连续或
  VINS lost-and-recover 后重收敛);验收=段2 到位精度(真值口径)与
  段间位置源行为记录
- **传送 harness(t3_verify_flight.sh)裁定:归档为 VINS 链路回归的
  压力工具,不作为验收协议**。理由:①实机无传送对应操作(架构裁定
  后语义失效)②其历史价值(GPS 代位链路的 EKF2 重锚损伤实证)已入
  台账结案③VINS lost-and-reloc 的独立验证价值已被两段式协议覆盖
  (段2 天然包含 lost/recover 面向实机的形态)。保留不删,引用时标注
  "非验收口径"

## 4. 场景矩阵语义(W2/A 系列在线版)

| 场景 | 激励 | 主判指标 | 机理数据 |
|---|---|---|---|
| 静置 | 地面/悬停静止 | ATE/漂移率 | — |
| 慢巡 | 0.3m/s | 到位+ATE | 特征数时序 |
| 冲刺 | 全速(0.5m/s+) | ATE+发散 | 运动模糊(合成图像边界对照) |
| 纯 yaw | ±120°×3 | yaw 漂移/速度秩亏表现 | 可观测性数据(T3 返程设计输入) |
| 降落 | z 阶降 | 全程 ATE | 下wash/近地特征 |

## 5. 五连飞(X4,tag sitl-v0.4 判据)

- 连续 5 轮两段式或短航线场景,每轮 §1/§2 全过(真值口径到位 <0.5m +
  ATE@60s<0.3m + 无 init 失败 + 无发散)
- 5/5 → tag `sitl-v0.4`(谁跑最后一轮谁打,打前查对方 STATUS)
- 任一轮失败:记录失败模式与根因归属(VINS/规划/控制/环境),修复后
  从头计数
