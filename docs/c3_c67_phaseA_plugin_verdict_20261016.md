## 二、机理分离实证（本域科学增量——判死因果链）

δ 探针实测（每轮随附 run 目录）：

| 档 | 有效频率 | 送达率 | 周期主峰 | 漂移中值 |

| 25Hz（S1） | 23.67Hz | 94.7% | 单峰化 40ms（2140）±1 步旁峰 36/44 | 1.295 |
| 15Hz（S2） | 14.97-15.01Hz | **99.8%** | 68/64ms（调度+4~8ms 固有滑移） | 1.123 |

1. **漂移率对相机节拍全域不敏感**：送达率 64%→94.7%→99.8% 三档、周期双峰→单峰→近匀，漂移中值 1.36→1.30→1.12（全程 > 门 1.7×）——"帧周期结构/送达率→慢漂"因果链**证伪**。
2. **δ=0 全程保持**（每组 ≥99.9% 帧左右同戳；非零帧仅 STARVE 重启边界）——丙册 H-src-2 条件现栈天然成立，L/R 配对面无异常。
3. **15Hz 仍有 ±1-2 步调度滑移**（主峰 67ms 而非理想 60ms）——该滑移为 gazebo sensor manager 调度固有相位，**SDF/launch 参数面不可达**（戳源语义域=空集已注记，丙册源码手术动机）。
4. **S3 免除理由**：其机理（depth 渲染让位→双目送达更稳）作用通道=同一送达率变量，S2 已达 99.8% 送达而漂移未动——通道已死，S3 无机理立足点（预注册"末步预算"条件不成立，如实注记非偷步）。
5. **轮级双态现象（新发现）**：全部 12 轮呈双态——净轮 0.30/0.44/0.83/0.93 vs 漂轮 1.1-2.25，三档频率同现 → 漂移驱动=**轮级状态变量**（VINS 初始化/估计器内部状态彩票）非节拍变量。与 C-3 史吻合（td0.005 净轮 0.385/0.787 同型）。
