# P0-2 立案件：判读双口径（min_surf vs 避障 min_dist）定案书

> 立案来源：《评审问题清单》P0-2（2026-10-16 宫浩杰评审）→ 本册 §一B.2 消费。
> 立案执行：③C-甲合流册 v5.2 执行者，2026-10-17 凌晨。
> 结论级别：**代码级+实证级定案**（非假设）——评审的"待证机制假设"被证伪，真机制更严重（判读器帧系+版本双错配）。

## 一、三列表（定义/驱动量/适用场景）

| 维度 | `min_surf`（geom 审计口径） | `避障 min_dist`（RESULT.txt 门口径） |
|---|---|---|
| **定义** | 真值轨迹点到各箱表面的逐箱最小净距（逐箱交互证明面） | 真值轨迹点对箱表的全体最小距离，>0.349 为过门 |
| **驱动量-轨迹侧** | `/gazebo/model_states` 真值（gazebo 原帧，**无锚修正**） | 同一真值流（gazebo 原帧，无锚修正） |
| **驱动量-箱表侧** | **逐 world 真表**（WORLD_TABLES[v6/v7/v8/v9]，gazebo 原帧坐标，如 cB1=(5.467,1.717)） | **v6 单表且被锚移位**（cB1=(4.457,0.737)=world 位姿−(1.010,0.980) anchor 偏移，即 odom 帧系） |
| **计算工具** | `corridor_geom_audit.py`（+v9ext） | `round_result.sh:144`（批 harness 逐轮 RESULT.txt） |
| **适用场景** | **正源**：③C 全部门组判读、S 形推导门、贴箱交互、结论 v1/v2 全部数字 | **污染态**：corridor 时代（v4→v9）所有 RESULT.txt 避障行、ok[1] 门位、TRICHOTOMY true_fail 分型参与量——**全部禁引** |

## 二、0.000 机制假设检验（评审假设 vs 实测定案）

- **评审待证假设**："末段漂移把 VINS 自报位置推进规划器地图占用格 → min_dist→0，而物理真值没碰箱"——**代码级证伪**：`round_result.sh:144` 的 `mind` 驱动量是真值（truth）非 VINS 自报、非规划器地图。假设方向错误，但"0.000 是算出来的数非缺省"的直觉正确。
- **实测定案（双错配）**：
  1. **帧系错配**：箱表为 anchor 移位后的 odom 帧系（v1.5c 注释自称"GAZEBO frame"但实现方向相反——表=world 位姿−anchor），truth 为 gazebo 原帧直比 → 全体 mind 值带恒定 ~(1.01,0.98) 系统偏移，"幻影箱区"整体偏离真箱 ~1.4m 对角。
  2. **world 版本错配**：v7/v7.3/v8/v9 批飞的是新箱位（如 v7.0 箱2 从 (8.020,1.107) 移到 (10.528,1.095)），RESULT 判读仍用 v6 表 → 幻影区与真箱完全脱钩。
- **实证样本**（argmin 探针，2026-10-17）：
  - `run_C3V8HOV2_051825`（悬停轮，RESULT 报 0.000）：truth 漂移至 gazebo (2.425,2.601,1.216)（t+148s）落入幻影 cN1 区（表 (2.544,3.100)±0.5）——**悬停轮物理漂进幻影区**，0.000 与避障行为无关。
  - `run_C3V7NE1_004543`（v7.0 导航轮，0.000）：truth 于 t+28s 经过 (2.271,2.601,0.809)——该处为 v7.0 world **空地**（真箱在 (3.419,4.229) 等），幻影 cN1 恰覆盖此处；cN2 同样命中 (5.37,3.80,0.39)。**导航轮穿越幻影区**，0.000 非碰撞。
- **批内分布复核**：172 个 run_C3* 中 0.000×65 / 非 0.000×83 / 无值×24——0.000 在 v7+ 批大面积出现（38%），与"幻影区覆盖新航线走廊"一致；评审所见 v6 时代"个别轮 0.000"= 幻影区与 v6 真箱仅偏 1.4m，命中概率低的时代差。

## 三、污染面与豁免面（数字对账）

- **污染面**：corridor 时代（v4-v9 全部批次）每轮 RESULT.txt 的"避障 min_dist"行及其 ok[1] 门位；TRICHOTOMY 分型中 true_fail 的避障门参与量；任何引用这些数字的叙述（含评审清单自引的 0.054-3.299 分布）。**历史 "RESULT 域 0 PASS/25 FAIL" 现象 = 到位严判 + 避障幻影 双因**，此前归因只列了到位严判。
- **豁免面（未污染）**：③C 正式门组判读全走 geom 审计工具（逐 world 真表+gazebo 原帧）；S 形推导门/贴箱窗配对/慢漂带/thrust/j0d 各面与 min_dist 无关；结论 v1 全部数字零引用 min_dist（复核见结论 v1 同步件）。

## 四、禁混用条款（入结论 v2 口径）

1. 对外一切"离障/净距/贴箱距离"陈述**唯一绑定 min_surf 口径**（真值×逐 world 真表）；RESULT.txt 避障行数字**禁止引用**（判读器缺陷在案）。
2. 任何旧文档引用 min_dist 数值的，加勘误指针指向本件。
3. `round_result.sh` 修复属判读器域：**修帧系（表改 gazebo 原帧或 truth 减锚）+ 接 WORLD_TABLES 逐 world 表**——与 corridor_geom_audit.py 同源同表。修复前该行输出加 `(CALIBER-BROKEN)` 后缀为过渡方案（是否执行=乙册/维护者裁定，本册只立案不改判读器——判读器语义禁改红线域）。
