## 一、结构事实（盘点前提）

- **相机 sensor 不在 world SDF 内**：v7.3 world（383a301a）无任何相机块；双目在无人机模型 `models/stereo_vins_rig/stereo_vins_rig.sdf`（iris_stereo_vins 包装，起栈注入）。盘点对象因此=模型 SDF+launch 链（域等效：均属 SDF/launch 级可达参数）。
- IMU 源=mavros `/mavros/imu/data_raw`（同实机架构，mavcmd 511 105 4000 → ~223Hz，4ms 网格锁定）——非相机插件域，注记。

## 二、可达参数全枚举（按机理相关性排序：时戳语义 > updateRate > 其他）

### A. 时戳语义类 —— **空集（如实注记）**

| 项 | 结论 |
|---|---|
| 戳源选择 SDF 参数 | libgazebo_ros_camera **无此参数**（header.stamp=SimTime 硬编码） |
| launch 级戳域开关 | `/use_sim_time=true`（sim_vins.launch 首行）= T2b-U6 冻结配方（1.79e9s 域分裂坑），**禁碰** |
| image 中转/节流/queue 节点 | **不存在**（VINS 直订 gazebo 相机话题，launch 无 image_transport/republish/throttle/queue 参数）→ launch 级节拍域=空集 |
| world physics step 4ms/RTF 1.0 | 非"相机插件参数"；被 IMU 网格锁（125Hz 量化锁+223Hz 配方）与 PX4 lockstep 双重依赖，**不可达注记** |

→ **移交丙册**（§一 S0.2 输入）：时戳戳源在 SDF/launch 参数面**不存在可达项**=其源码手术（消费侧戳吸附/插件手术）的动机证据；丙册禁重复盘点（STATUS 通告另发）。

### B. updateRate 节拍类 —— **有实measured异常，主候选域**

实测证据（C-6 批在飞轮 δ 探针，/tmp/c3_delta_*.tsv，2026-10-16 实算）：

1. **左右目 δ=0 占 99.9%**（VFE5 5895/5897、VFE8 2583/2584、VFNE4 5916/5921；非零帧仅 STARVE 重启边界帧，δmax=68ms）→ **L/R 配对不是现行异常**（丙册 H-src-2"左右同戳 δ=0"条件在现栈已天然成立）。
2. **有效帧率仅 19.2Hz（名义 30Hz，丢帧 36%）**：VFE5 span=307.4s n=5897 → 19.19Hz；VFNE4 19.29Hz。
3. **周期直方图双峰**：36ms×1202 + 64ms×1180 + 40-80ms 长尾（VFE5 全文件）；**全部戳严格落 4ms 网格**（off-grid=0）。
4. 机理判读：30Hz 周期 33.33ms 在 4ms 步长网格上不整除（8.33 步）→ 量化 beat+渲染槽滑失交替（36=9 步 / 64=16 步=整帧滑掉）→ **节拍域唯一实 measured 可攻面**。

|---|---|---|---|
| sensor `<update_rate>`（双目两实例同值） | stereo_vins_rig.sdf | 30 | **主候选**（S1/S2） |

## 三、预注册步骤（≤3 步停规则；每步=配对实验红线④）

**采纳门（跑前锁定，承 C-1 冻结口径）**：改参组悬停漂移率中值 **≤0.65m/min**（稳定主段=truth z≥0.9 连续最长段 XY 首末位移/时长；工具 c1_drift_rate.py）。
**配对制**：每步=同会话基线悬停 ≥3 轮（不改参）+改参悬停 ≥3 轮；基线组中值须落 **[1.1, 1.8] m/min** 在册带（出带=窗环境异常该步作废重测）；各步独立对基线禁叠加。
**悬停轮配方**：vins_smoke.sh --world sitl_world_corridor_v73（**注意用 v73 正名**，见 C66 勘误件）--goal 1.51 0.98 1.0 --budget 90；tag=C3A2B{r}/C3A2S{step}{r}（B=baseline）。
**伴生约束（中值进带才做）**：①悬停窗 stereo 配对率 p50≥0.10；②起飞面复验 ≥3 轮（thrust 不劣化+零弹射+判读兼容性注记）；③每步悬停轮 j0d 证书（观察面不设门；跳变同步改善=时戳共根旁证注记入案）。

### S1（首步）：双目 sensor `<update_rate>` 30 → **25**

- **机理假设**：25Hz 周期 40ms=4ms 网格 10 步整除→消除 36/64 量化 beat；渲染预算/帧 +20%（33.3→40ms）→ 槽滑失率降。预期信号链：有效频率→~25Hz 单峰 40ms 周期 → VINS 输入节拍均匀化 → 若慢漂驱动在节拍/transit 域（C-3 停止注记归因"渲染时戳域"），漂移率中值下探。因果链=本步受检假设（诚实注记：周期均匀化→漂移改善的因果未证，正是本步要验的）。
- **操作**：stereo_vins_rig.sdf 双目两处 `<update_rate>30`→`25`（同值改=单参数单变量；**禁只改一目**——人为制造 δ）。原文件备份+md5 记录；步末未采纳即还原。
- **配对复测方案**：基线 3 轮（30Hz 原态）→ 改参 3 轮（25Hz）；δ 探针随轮（复测周期直方图验证节拍面假设）；判读=漂移率中值+周期直方图+配对率。
- **采纳门**：见上（≤0.65）。未达带=不采纳（改善幅度注记不作为采纳理由——C-3 parallax5.0 先例）。

### S2（次步，仅当 S1 未达带且 S1 仍显丢帧/双峰）：update_rate 25 → **15**

- **机理假设**：60ms=15 步整除+渲染预算 80% 富余→强制单峰。若 S1 后周期已单峰但漂移未动=节拍假设证伪方向证据（S3 换机理面）。
- 独立对基线（30）配对复测，同 S1 方案。

### S3（末步预算）：depth_camera sensor `<update_rate>` 10 → **5**

- **机理假设**：深度渲染（10Hz depth+点云）与双目渲染竞争 GPU/渲染线程；让位后双目槽滑失率降。基线态=depth 10（对基线配对，不叠加 S1/S2 结果）。
- 5Hz=200ms=50 步整除；避障供给影响由伴生约束①②把关（planner 点云降频——起飞/导航面复验覆盖）。

≤3 步；**两连续步无显著改善可提前停**；不达带=**终局停止注记**（"yaml+插件两层域合力不可达"，含量化最佳值：在册 1.197/0.385/-58%（config 域）+ 本域各步值均入表，禁只写"不可达"三字）。
