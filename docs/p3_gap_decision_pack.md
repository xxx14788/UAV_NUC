## 1. 阻断级（不缓解不得飞）

### A1 实机外参实测标定

- **现状**：sim 侧外参=SDF 刚体链手推 hack（ext0 已钉死 tic；include 覆盖 bug 真值 z=−0.02 已勘误，
  T3 v7.1 台账）；实机侧无实测值。瞬态发散五例+T2-WA9 剩余变量（近距视差结构）仍把外参先验误差
  列头号候选族。
- **实机风险**：阻断。竖直机动对外参 z/pitch/roll 误差杀伤大（E12/E13 实测）；手推值不可迁移。
- **缓解或接受建议**：CAD 推导+手眼标定先行，标定优先保 z/pitch/roll（runbook §1 对策行）；
  结果按 README §3 登记入库后，S1-S3 全门重跑。
- **归属**：T2（外参策略与 yaml 落库）+实机组（标定操作）。

### A2 地面 init 纪律（移动中 re-init 0/5）

- **实机风险**：阻断（流程级）。空中失效后无恢复手段，唯一出路是落地。

### A3 起飞/瞬态发散根因收口（W-C2 六轮硬前置）

## 2. 高风险（缓解后可带风险飞）

### B1 慢漂双层（噪声慢漂=纯视觉架构属性）

- **现状**：两层现象已定标（t2_experiments.md E6 章）：①**噪声慢漂**=架构属性，σ_w=0.069/0.071
  两代一致，悬停包络 ~0.75m 有界；0.1m/s 档 T_detect=60s 泄漏上界 6.0m。②**毒慢漂**（bias 恒向+
  速度过估固化，10-100m 级）=可修层，已随 gyr_w 修复收口。实测量级：0.468m/3min（轮3，无回环）；
  到位门 <0.5m 单轮通过率 ≈1/2（慢漂限制）；悬停保持中位 0.005m/V1 量级 0.12m 级。
- **实机风险**：高——直接吃 S2/S3 到位与 ATE 门；实机振动或加剧（无 sim 域对照）。
- **缓解或接受建议**：接受为架构属性不硬怼：S2 限定 2m 往返短航线先验证；到位门改
  「≥3 轮统计口径」而非单轮 0.5m 硬门；S3 返航保守半径（runbook §3 已注）；无回环→不排长航线。
- **归属**：T3（航线半径/返程设计补偿）；用户（门宽口径拍板，§5 Q2）。

### B2 重锚尖峰/位姿跳变直入控制环

- **现状**：VINS 重锚微跳=架构属性（t1_vins_odom_contract 连续性行）；SITL 实测单次 2.45m 跳变
  瞬态（WAOL5R）+重锚伴随 |v|≈1.15m/s 尖峰（V1 线台账）；W-D1 平滑重锚 replay A/B 8904→0 已入库
  （T1 v6.1），但 47s 型大重锚仅部分补偿（0.05/0.207）。
- **实机风险**：高——vision_pose 阶跃无衰减直进 px4ctrl 位置环（F2 裁决后控制主环完全吃 VINS）。
- **缓解或接受建议**：W4 跳变门保持启用（现行）；U5 IMU 一致性门维持关闭直至 v2 改造+三工况零
  误报回归（runbook §2.5/§6 现行口径）；发布端有界性防线版本上机前确认（§2.6）。
- **归属**：T1（门+防线版本管理）；T2（重锚机制根因线）。

### B3 EV 启用问题（决策项，三选一）

- **现状**：EV_CTRL=0 全历史（EV 融合从未启用，E1 台账）；W2 五场景全灭归因 EKF2-EV 控制层
  （t2_experiments.md W2 章）；F2 裁决后实机不吃 EKF2 位置输出——EV 融合即使启用也只影响
  mavros local_position 链路（vins_to_mavros→vision_pose→EKF2→?），不在控制主环（F2_closure）。
  EV 失流劣化实测：w2b z 飙 3.8m。
- **实机风险**：中-高（取决于决策；启用即引入未验证链路，禁用则 local_position 参考链裸奔）。
- **缓解或接受建议**：三选一入 §5 Q1——①维持禁用（与 SITL 同构，最简，推荐）②启用仅作链路
  冗余监控位 ③启用+PX4 EV 超时参数与降级策略评审（runbook §4 行，与 T1）。任选其一均须
  首飞前把决策写回 runbook §4。
- **归属**：用户拍板（§5 Q1）；T1 执行参数评审。

### B4 FOV/fx 尺度迁移一阶项

- **现状**：fx 比 1.2071（sim 467.74 vs 实机 yaml 387.51）→「实机经验反推 sim 深度偏差 ~+21%」
  一阶风险；sim 视场窄 13.1%H/14.5%V；hfov 单参数可对齐（六维表视场行）。
- **实机风险**：中-高——方向有利（sim→real 视场变宽、特征供给只会更好），风险在**参数先验迁移**：
  把 sim 调好的特征/阈值参数原样搬实机会因尺度一阶项失配。
- **缓解或接受建议**：实机首飞全部用实机自身标定参数（禁止 sim fx/特征参数直接迁移）；
  hfov 对齐与参数面五方对照归 T2-A2 排期（低优先）。
- **归属**：T2-A2。

## 3. 中风险（接受+监控）

### C3 yaw 慢漂无绝对参考

- **现状**：VINS yaw=init 时机头向，无绝对参考慢漂（t1_vins_odom_contract 原点/yaw 行）；
  纯视觉红线=磁力计不参与定位链；yaw drift <5° 监控口径已定（runbook §4 磁干扰行）。
- **实机风险**：中——返航精度随航线长度/时间衰减；短航线内受控。
- **缓解或接受建议**：S2/S3 包络内接受；S4 起每轮记录 yaw drift 时序，>5° 即收半径并记录。
- **归属**：T3（返程设计输入）；T4（判读口径已备）。

### C4 深度 INIT_DEPTH 静默伪深度

  深度域硬门控=T2 主线；两侧正源挂账③。
