## 3. 一页设计方案：C1 悬停门控零速软约束（t2_zupt）

**目标**：悬停/低速段把位置随机游走的主链路（速度小偏差积分）钳住，降低 σ_w 与到位尾差；不引入新跳变源。

**门控（自包含，SITL/实机同构，不依赖控制栈信号）**——照搬 OpenVINS 双门控思想：
- G1 IMU 轴：滑窗最近 N=10 帧 IMU 速度估计均值 ‖v̄‖ < t2_zupt_gate_v（默认 0.10 m/s，对巡航 0.5m/s 有 5× 裕度）；
- G2 视差轴：近期帧间平均视差 < t2_zupt_par（默认 0.5px，D435 悬停天然近零）；
- G3 附加守卫：solver_status 非 init 段才可门控；重锚事件（T1 域）后 gate 冷却 1s 复位。
- 双门 AND 连续保持 t2_zupt_hold（默认 0.5s）才置 hover_flag。

**残差形态**：ceres 软约束——对 gate 窗口内每帧速度状态加 ‖v_k‖ 二范数残差，噪声 σ=t2_zupt_sigma（默认 0.05 m/s）。**禁硬等式约束**（防与视觉观测打架）；gate 期间每帧加一次，不回溯不加历史帧。

**开关族**：`t2_zupt`(0/1，默认 **0**)+上述四个子参——沿用 t2_* 防线开关族模式（canonical 裸驯化栈默认全关，红线 12）。

**一变量纪律在线验收**（X 线后）：
1. A/B：同场景 hover 轮 ×{off,on} 各 ≥3（U3 矩阵扩容条款可复用轮次）；
2. 指标：σ_w 复测（`analysis/t3_e6_drift_budget.py` 直接复用）+ 60s 尾窗包络 + 四指标双口径 + J0 修订口径 + 跳变计数（必须与 off 基线同分布=不引入新跳变）；
3. 通过线：σ_w 降 ≥30% 且四指标零劣化且跳变计数不增；
4. 回归：obstacles/route 各 1 轮机动域抽查（验误门控零形态）。

**gtest 扩用例**：①gate 判定单测（速度/视差双门+守卫真值表）；②残差雅可比数值校验。

**明确不做**：不碰六维排除结论；不做归因；不动 T1 重锚域代码；不启用 loop_fusion（C4 登记即止）；实机 D435 零改动（门控输入=IMU+视差，传感器侧无改）。
