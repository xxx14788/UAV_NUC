## 3. 错列 d 与织行幅度推导（含 45° 对角支撑勘误注记）

- 任务书公式（轴对齐代数）：封线条件 **d < 0.3+0.299 = 0.599**；织行幅度 **A = 0.599−d = 0.42**（d=0.18）。
- **勘误注记（本设计新增，不影响门值）**：lane 为 45° 对角，轴对齐方箱在对角方向的膨胀支撑 = 0.3√2+0.299 = **0.723**（非 0.599）。故：
  - 封线判定不变（d=0.18 < 0.599 < 0.723，两种口径均封线 ✓）；
  - 物理最小织行幅度 A_geo = 0.723−d = **0.543**（正弦向 abeam 通过需求）＞ 任务书 A=0.42。A=0.42 保留为**门值基准**（maxlat 门=A−0.10=0.32 的锚），实际成功 S 形轮幅度预期 ≈0.55+。
  - 数值验证：直线穿舱被膨胀区阻断（inside 测试 True）；无约束最短避障路径=6.2642m（单侧 C 形），交替 S 形最短=6.3571m。
