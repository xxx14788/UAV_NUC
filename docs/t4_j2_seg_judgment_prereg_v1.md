## 2. 协议（v1，冻结；改动须新版本号重新预注册）

1. **采样单元**：cell(bag, seg k) 的段级 P50（k∈{0,1,2}；seg=ALL 行不重判，袋级结论正本=
   verdicts §2 J2 正式判读不动）。指标=M1_supply_frac、M2_grid4x4_occupancy_frac，原值列。
   数据正源=`sitl_sim/t4_evidence/v55_20261003/derived/pool_m1m2_byseg.csv`（commit 49d2ac3，
   md5 前 8 位 9aa68e43）。
2. **门**：对每个 (seg k, 指标)，取六袋 cell 值的跨袋产额分位 P10/P50（线性插值，
   numpy.quantile 默认法）；P90 仅登记不设门（n=6 下无判读用途）。舍入仅在显示层（4 位小数），
   判定比较用全精度。
3. **三态（位次语义，与袋级 正常/观察带/嫌疑 语义隔离）**：
   前位 = cell P50 ≥ seg P50 门；中位带 = P10 门 ≤ cell < P50 门；低位旗 = cell < P10 门。
4. **CI 降级（保守规则，单域不下死判的位次版延伸）**：非中位带 cell 若其门值严格落入自身
   CI 区间（CI_lo < 门 < CI_hi），降为**中位带（CI 跨门降级）**并显式标注。
5. **语义与边界**：低位旗=**同批六袋内相对位次旗**，唯一用途=@T2 复核优先序注记素材；
   不构成任何袋级嫌疑的新立或升降级，不构成 FAIL 行（FAIL 两味标注规则零触发面）。
   **循环性声明**：标定集=判读集同源（六袋自校准），为 v1 固有边界；cohort 构成=主池 3
   （U3PG/U3PO/U3PR2）+扩展池 3（U3PH/U3PR1/X1final），位次结论不得外推至本 cohort 外。
6. **复现**：判定脚本一次运行落盘 `derived/j2_seg_judgment_v1.csv` + `j2_seg_judgment_v1.md`
   （含门值表与 36 判定位），脚本 md5 与产物 md5 双登记；任何人重跑应逐位复现。

## 2a. 计算口径（v1 补充条款，先于首用判定产物落盘）

- 一切门值与比较运算用**十进制定点**（decimal.Decimal，csv 字符串直读），禁二进制浮点参与判定。
- CI 跨门判定为**严格不等式**（CI_lo < 门 < CI_hi）：门恰等于 CI 边界=不跨，不作降级。
- 依据：n=6 门为两点均值，与 cell CI 端点存在精确相等的真实情况（在册实例：U3PR1 seg1 M1
  门=0.8200000000 恰等于其 CI_lo=0.82），二进制浮点噪声会翻转此类边界格判定，违背逐位复现要求。
- 实测注记：浮点实现（float64）在精确相等边界格产出与本条款相悖的结果（2026-10-04 首跑实锤：
  U3PR1 seg1 M1 门=0.8200000000 恰等于 CI_lo=0.82，浮点判成"跨门降级"而十进制正确判"前位"——
  仅此 1 格受噪声影响；U3PR1 seg2 M2 的跨门降级为真实跨门，两种口径一致，不属噪声）。本条款即为此立。
